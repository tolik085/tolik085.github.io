Privacy Policy

Home Studio Publisher · last updated 20 September 2026

1. Summary

Home Studio Publisher collects no personal data from anyone. It has no users other than the owner of Home Studio, no accounts, no sign-up, no analytics and no third-party trackers.

2. What the tool stores

To publish to TikTok the tool stores, on a single private computer:

  • an access token and a refresh token issued by TikTok for the owner's own account;
  • the TikTok open ID of that same account;
  • the video files and captions created by Home Studio for publication.

These are held in a local file on that computer. They are never uploaded to any server, never shared, never sold and never transferred to a third party.

3. What the tool does not do

  • It does not read, collect or store data about other TikTok users.
  • It does not access followers, comments, messages or private information.
  • It does not use any data for advertising, profiling or model training.
  • It does not send data to analytics providers, because it uses none.

4. Retention and deletion

Tokens are kept only while the tool is in use and can be deleted by removing the local credentials file. Authorisation can also be revoked at any time from TikTok account settings, which invalidates the stored tokens immediately.

5. Children

The tool is not intended for, and is not made available to, anyone under 18.

This policy may be updated. The date above shows when it last changed.
